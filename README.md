Testes Automatizados com Maestro

Este repositório contém testes automatizados desenvolvidos com Maestro e executados num tablet Android 15.

 Teste 1 — criar conta (1_criar_conta.yaml)
 Fluxo completo de criação de conta.
* O token de verificação é inserido manualmente durante a execução.
* A seleção do campo "Verificar" deve ser realizada manualmente.
----------------------------------------------------------------------------------------------------
 Teste 2 — login de conta (2_login_conta.yaml)
Realiza autenticação, valida elementos da home e efetua logout.
----------------------------------------------------------------------------------------------------
 Teste 3 — criar atividade (3_criar_atividade.yaml)
 Inicia uma atividade, termina a sessão e realiza logout.
